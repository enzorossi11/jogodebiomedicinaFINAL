# Regra de Acessibilidade Sensorial para Agentes

Ao editar ou criar telas, componentes visuais ou cenas 3D no repositório:

1. **Nunca adicione elementos estroboscópicos ou piscantes.**
2. **Nunca torne áudios obrigatórios para o entendimento da atividade.**
3. **Nunca bloqueie os botões de navegação ("Voltar" e "Próximo órgão").**
4. **Mantenha o botão "Observar sem tocar" em toda animação biológica.**
5. **Nunca use cores vermelhas punitivas ou sons de erro estilo "buzzer".**
6. **Sempre limpe recursos Three.js (`dispose()`) no retorno dos hooks `useEffect`.**
