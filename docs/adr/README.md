# Registros de Decisões de Arquitetura (ADRs)

Este diretório armazena os **Architectural Decision Records** (ADRs) do projeto. Toda decisão técnica relevante de longo prazo (escolha de bibliotecas, estratégias de renderização gráfica, padrões de acessibilidade ou mudanças de paradigma) deve ser registrada aqui.

## Como Adicionar uma Nova Decisão

1. Copie o arquivo [0000-template.md](file:///c:/Users/bruno/OneDrive/Área%20de%20Trabalho/jogodebiomedicina/docs/adr/0000-template.md).
2. Nomeie o novo arquivo seguindo o padrão numérico sequencial: `000X-nome-sucinto.md`.
3. Preencha todas as seções (Contexto, Decisão Tomada e Consequências).
4. Adicione o link para a nova decisão na lista acima.
